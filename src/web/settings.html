Settings

Maze visuals apply instantly to the open maze tab. Gmail credentials are stored locally as credentials.json (mode 0600) and never leave this machine.

Maze UI

Stored in this browser only (localStorage) and saved automatically as you change anything. Applies live — keep the maze open in another tab and tweak away.

Last trash run

Restores the messages from your most recent trash run back to the Inbox (Gmail also keeps them in Trash for 30 days).

Gmail API credentials

Create an OAuth client (Desktop app) in Google Cloud Console, then either upload its JSON file or paste the fields. Saving overwrites local credentials.json. First Gmail access still happens via scan, which opens the Google consent screen.
